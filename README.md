# Send to MPC

Drag and drop WAV or AIFF samples, complete drum kit folders with `.xpm` programs, and compatible MPC VST2 plugin folders onto a standalone Akai MPC over SSH.

[Download the Mac and Windows bundle from Releases](../../releases). The bundle includes a color quick-start guide.

- **Mac:** Apple silicon, macOS 14 or later.
- **Windows preview:** x64 with OpenSSH Client enabled. This build awaits testing on a Windows PC.

On MPC OS 3.10.1, enable SSH through Developer Mode. Connect the MPC and computer to the same local network, enter the MPC's IP, and click **TEST**. Choose a writable destination on the MPC before dropping files. For VST2 plugins, select the `VST2 Plugins` folder at the root of the drive and enable External Plugin Support on the MPC.
